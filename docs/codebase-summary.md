## `api/`

| File | Purpose |
|---|---|
| `main.go` | `main`, `run` (graceful shutdown), `newStore` (Turso vs memory; refuses memory on Render) |
| `config.go` | `loadConfig`: `PORT`, `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`, `ALLOWED_ORIGINS`, `RENDER`; rate limit (5/min, burst 3) set here |
| `server.go` | `newServer`: middleware chain, routes, `jsonErrorHandler`, `bindJSON`, `parseLimit` |
| `client_ip.go` | `clientIPExtractor`: X-Forwarded-For, or Cloudflare headers on Render |
| `wish_handler.go` | `listWishes`, `createWish` (honeypot) |
| `score_handler.go` | `listScores`, `createScore` |
| `store.go` | `Wish`, `Score` types, `Store` interface, `newID`, `nowUTC` |
| `store_turso.go` | `tursoStore`: libSQL client, schema, queries with 5 s timeout |
| `store_memory.go` | `memoryStore`: dev and tests |
| `validate.go` | Name, message, score validation and cleanup |
| `Dockerfile` | Multi-stage: `golang:1.26-alpine` build, `distroless/static:nonroot` run, `PORT=8080` default |
| `.dockerignore` | Excludes `.env*`, `*.md`, `*_test.go`, `Dockerfile`, `.git` from build context |
| `go.mod` / `go.sum` | Module `danh-birthday/api`. Echo v4, libsql-client-go, x/time, x/text |
| `*_test.go` | `server_test.go` (routes, 429, 413, CORS), `validate_test.go`, `client_ip_test.go` |

## `tools/fetch-assets/`

| File | Purpose |
|---|---|
| `main.go` | Flags `-out` (default `../../site/assets`) and `-force`. Fetches avatar, headshot, game art, fruits, wearing; writes JSON data |
| `roblox_api.go` | Roblox public API calls: thumbnails, game icons, currently wearing, asset details |
| `download.go` | `download(url, dest, force)`; returns `errExists` when the file is already there and `-force` is off |
| `image_optimize.go` | PNG/JPEG resize and flatten to page background |
| `go.mod` / `go.sum` | Module `danh-birthday/fetch-assets`. Depends on `golang.org/x/image` |
